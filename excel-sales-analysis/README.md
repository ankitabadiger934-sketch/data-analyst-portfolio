# Excel Sales Data Analysis

## Objective
Analyse sample sales data to identify sales trends.

## Tools
Microsoft Excel

## Work Completed
- Cleaned the dataset
- Used formulas and PivotTables
- Created charts
- Summarised key findings

## Results

Analysis of 10 fictional sample sales records:

- Total sales: ₹2,81,500
- Total profit: ₹43,900
- Total quantity sold: 51 units
- Highest-sales product: Laptop, with ₹2,00,000 in sales
- Highest-sales region: East, with ₹87,500 in sales

## Key Insights

- Laptops contributed the highest sales value.
- The East region recorded the highest total sales.
- The sample data can be used to practise Excel formulas, PivotTables and charts.

Note: This project uses fictional practice data.
